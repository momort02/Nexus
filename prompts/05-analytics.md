# Prompt 05 — Server Analytics

Implémente le module Analytics selon `docs/SPECIFICATIONS.md`.

Attendus :
- schéma de statistiques agrégées par guild, salon et période ;
- collecte des arrivées/départs et compteurs de messages ;
- définitions documentées de « membre actif » ;
- endpoints paginés et filtrés ;
- dashboard avec graphiques Chart.js ;
- comparaison de périodes ;
- export CSV ;
- états loading, empty et error ;
- isolation stricte par guild ;
- tests des calculs et autorisations.

Ne stocke pas le contenu des messages. Ne fabrique pas de données réelles. Les jeux de démonstration doivent être identifiés comme tels.
